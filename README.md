# MUSCLE ATLAS (MA) — MARK 4

Mark 3는 유지하고 별도 Android 앱 ID로 구성한 Mark 4 프로젝트입니다. 앱은 기존 Android WebView 구조를 유지하며 HTML, 데이터, 시각화 코드를 앱 자산에 포함해 오프라인 동작을 목표로 합니다.

## 이번 버전

- 운동 데이터 1,500개: 기존 200개 기본 운동을 바탕으로 1,300개 템포·정지·좌우 교대 등의 변형 항목을 추가했습니다. 따라서 1,500개가 모두 서로 완전히 독립적인 운동 패턴을 의미하지는 않습니다. 변형 이름·ID는 중복되지 않지만, 새 변형 설명과 운동별 그림은 추가 검토·보정이 필요합니다.
- 검색, 부위·난이도·운동 방식·목적 필터와 페이지 나누기(페이지당 30개)
- 운동 상세 정보, 주요/보조 근육 표시, 관련 운동
- 운동 루틴(검색 후 체크박스로 추가/제거), 운동별 세트·반복, 저장 루틴의 완료 기록, 체중 기반 참고 칼로리 추정
- 로컬 저장, 근육 분석, 근육학 TIP, 백업·복원
- 운동 자세와 근육 지도를 위한 경량 WebGL 시각화: 직접 생성한 매끄러운 단일 표면 인체 메시 10종(총 약 46,800개 정점)을 여러 운동이 공유합니다. 정면·측면·후면 보기, 드래그 회전·확대 지원
- WebGL을 사용할 수 없는 환경을 위한 단순화된 2D 대체 표시. 대체 모드에서는 부드러운 실제 3D 회전이 보장되지 않습니다.
- 모든 모델/데이터는 로컬 자산으로 제공하며 외부 CDN이나 원격 모델 파일에 의존하지 않습니다.

## 중요 사항

3D 모델은 고폴리곤 GLB가 아니라 메시를 앱에 내장한 경량 인체 모델입니다. 10개의 기본 자세 메시를 운동군별로 재사용하며 별도 텍스처나 외부 다운로드는 없습니다. 현재 자동 UI 테스트 환경에서는 WebGL 컨텍스트를 생성할 수 없어 실제 GPU 렌더링을 확인하지 못했습니다. 메시 데이터 복원과 인덱스 범위는 검증했지만, 실제 Android WebView/BlueStacks에서 매끄러운 3D 회전이 되는지는 설치 후 확인해야 합니다. 모든 1,500개 변형의 자세가 정확한 것도 아니며, 현재 자세 표현은 대표 동작군을 기준으로 한 개념 모델입니다. 운동 변형별 설명·근육 기여도 역시 전문적으로 개별 검수된 1,500개의 독립 동작은 아닙니다.

## 새 GitHub 저장소에 올리기

1. ZIP을 압축 해제합니다.
2. 압축 해제 후 나온 **내용물 전체**를 새 GitHub 저장소의 최상위 루트에 올립니다. 폴더 한 겹을 더 넣지 마세요.
3. 저장소 루트에서 `settings.gradle`과 `app`이 보여야 하며, 워크플로 파일은 `.github/workflows/build-apk.yml`에 있어야 합니다.
4. `Actions`에서 빌드가 성공하는지 확인합니다. 검증 단계와 Android Gradle 빌드가 별도로 실행됩니다.
5. 성공 실행의 Artifacts에서 `muscle-atlas-mark4-apk`를 다운로드하고 압축을 풀어 `app-debug.apk`를 설치합니다.

## 자동 검증

GitHub Actions는 빌드 전에 `python tools/validate_project.py`를 실행합니다. 데이터 수, ID/이름 중복, 필수 필드, HTML 내장 데이터와 `data.json`의 일치, 3D 메시 데이터, 루틴 선택 핸들러, JavaScript 문법 및 APK 업로드 경로를 점검합니다. 이 정적 검증은 실제 기기에서의 GPU 3D 렌더링 테스트를 대신하지 않습니다.

## 칼로리 추정 주의

표시되는 값은 세트·반복 수, 운동 종류·부위와 입력 체중을 사용하는 참고용 추정치입니다. 실제 중량, 운동 시간, 휴식 시간과 개인차를 완전히 반영하지 않는 측정값이 아닙니다.
